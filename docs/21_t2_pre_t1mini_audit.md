## 二、为什么公开表格的 γ̂ 不可信（本会话独立诊断）

用修正版报告自己列出的相机轴数据（7 个模型）重跑：

```
全部 7 点            : gamma = 14.68   SE 4.22   ~95%CI [4.9, 24.4]   R2=0.708
去掉 OpenVLA(clean 76.5%) : gamma = 56.94   SE 21.4   ~95%CI [7.5, 106.4]  R2=0.639
其余任一点留一法        : gamma = 13.9 ~ 15.6
```

**七个点里去掉一个，γ 跳 4 倍；去掉其余任何一个都几乎不动。**
整个估计由单个低能力杠杆点撑着。

根子在于 x 轴范围退化：

| 子集 | log-x 跨度 | log-y 跨度 | 比值 |
|---|---:|---:|---:|
| 全部 7 点 | 0.244 | 3.994 | 16 |
| 高能力 6 点 | **0.035** | 2.631 | **74** |

预测变量几乎不动、响应变量狂跳 74 倍时，拟合出来的「斜率」不是斜率，
**是纵向散布除以一个接近零的横向跨度**。

旁证：同一批数据，潜变量二项模型给 35.84 [29.5, 44.3]，OLS 给 14.68 [4.9, 24.4]——
**两个区间不重叠**。这本身就说明模型设定有问题（前者忽略跨架构方差，正如修正版附录所承认）。

另外两个技术问题：
- 乐观版对 clean 与 OOD 都用 $n=500$。修正版指出 OOD 侧其实是每轴 1,076–1,601 个任务、**每任务仅 1 trial**。
  把「一堆各跑一次的异质任务」当作 $\text{Binomial}(500,p)$，n 错、且存在过离散。
- $n=10$ 的 Spearman 标准误约 0.33。$\rho\in[-0.19,0.38]$ **不构成**「PDR 系统性颠倒排序」的证据。

## 三、但数据里有比 γ≠1 更好的东西

修正版自己的 Observation 2，把它当主角而不是配角：

```
6 个模型，clean SR 94.2%–97.6%（窗口仅 3.4 个百分点）
相机轴 OOD：4.3%  →  59.7%     跨度 55.4 点，14 倍
```

**在部署相关的高能力段，干净成功率几乎解释不了任何东西。**

这正好和 `2602.03344`（*Robustness as an Emergent Property of Task Performance*，
2026-02，cs.CL）**方向相反**——那篇在静态 NLP 任务上证明鲁棒性由 task competence 驱动，
并据此建议减少对鲁棒性的独立投入。

> **闭环操作里，同等能力的策略之间鲁棒性差 14 倍。
> 「鲁棒性随能力自然涌现」在这里不成立。**

这个命题比 γ≠1 强在四点：
1. **不需要在退化的 x 范围上估斜率**——只需要 matched-capability 比较，数据强力支持；
2. 它是对一篇新近论文的**指名反驳**，且在新领域；
3. 它有具体的机制候选（见下）；
4. 它顺带救回了实用主张：**若能力不预测 OOD，那么 PDR 除以能力就不是在去混杂，而是在加噪声。**

### 机制候选：观测冗余（需要实验确认，目前只是假设）

| 分组 | 相机轴 OOD | 均值 |
|---|---|---|
| 带 wrist camera（OpenVLA-OFT, OFT_m） | 59.7%, 57.9% | **58.8%** |
| 仅第三视角（OFT_w, π0, UniVLA） | 16.8%, 15.8%, 4.3% | **12.3%** |

相差 **4.8 倍**。
**但必须说清楚：这两组的 clean SR 也不同**（97.4% vs 94.9%），能力与是否带腕部相机在这个小样本里
**是混杂的**。2.5 个百分点的能力差不太可能解释 4.8 倍的 OOD 差异，但 5 个点不足以定论。

→ 这恰好是一个可以在 4080 上干净识别的实验：**固定架构族，只增删腕部视角，
用 checkpoint 选择把 clean SR 匹配齐**。ACT / DP 都能训。

## 四、T1-mini 与 T2-PRE 方向相反——这是信息，不是矛盾

| 来源 | 范围 | γ̂ |
|---|---|---|
| T1-mini-real（ACT 单族，5 checkpoint，冒烟数据 n=10/格） | **族内** | 相机 **0.911** (SE 0.430)、物体位姿 **0.611** (SE 0.212)，CI 均覆盖 1 |
| LIBERO-Plus 公开表格 | **跨架构** | 3.5 – 36 |

**族内斜率 ≈ 1，跨族斜率 3.5–36。二者之差就是架构残差。**
这正是修正版提出的「能力效应 + 架构/训练残差」分解，而数字已经显示**架构项占主导**。

T1-mini 是 1 个任务、每格 10 个 episode 的冒烟数据，报告自己也标明"不得作为论文实证证据"——
这一点做得对，不要改。它的价值在于**给出了族内斜率的第一个方向性读数**。

## 五、后果：旧的 kill 规则会杀掉真正的发现

预注册的旧规则是「γ≈1 → 停 C1、转 C3」。

按新框架，**族内 γ≈1 恰恰是预期的零假设，是让架构残差成为主角的前提**。
照旧规则执行，T1-A 一跑出 γ≈1 就会把项目停掉——而那正是结论。

### 修订后的假设与 kill 规则

**主假设（新）**
- **H1′**：在匹配 clean capability 的条件下，跨架构的 OOD 成功率仍存在大幅离散
  （相机轴预期 ≥5 倍），即 capability 不足以决定闭环鲁棒性。
- **H2′**：族内（同架构、沿 checkpoint）的能力效应显著弱于跨族的架构残差；
  两者之差可量化。
- **H3′**：按 PDR 排序与按（族内曲线校准后的）残差排序给出不同的模型序。

**次要/诊断**
- 原 H1（γ≠1）降级为族内曲线的形状描述，不再是论文的主张。
- 原 H2（α_H 关于 H 线性）保留为机制探索。

**新 kill 规则**
| 结果 | 行动 |
|---|---|
| 匹配能力下跨架构离散很小（capability 基本能解释 OOD） | **停**。2602.03344 的结论延伸到机器人，我们没东西 |
| 离散大，但完全由某一个 outlier 架构造成 | 降级为 case study，不是一般规律 |
| 离散大且跨多个扰动轴稳定 | **成立**，按新主假设推进 |
| 观测冗余（腕部相机）假设在受控实验中不复现 | 保留 H1′，去掉机制段，故事减半但仍可发 |

## 七、给 T1-A 的三条硬性追加

1. **clean SR 跨度 ≥60 点**，按 7 个 bin × 3 seeds 执行，不得再降。
2. **必须同时报告族内斜率与跨族匹配能力离散**。只报其一无法支撑新主假设。
3. **加一组观测冗余对照**：同一架构、同一数据、只增删腕部视角，
   用 checkpoint 选择把 clean SR 匹配到同一 bin。这是把「机制候选」变成「机制证据」的最短路径。
