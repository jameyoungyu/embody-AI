## 一、要检验的命题

### 1.1 PDR 的隐含模型

VLA 鲁棒性文献普遍使用 Performance Drop Rate：

```
PDR = (p_clean − p_ood) / p_clean
```

把它当作可跨模型比较的鲁棒性指标，等价于假设扰动的作用是**成比例**的：

```
p_ood = c · p_clean                                   (H0)
```

嵌入幂律族：

```
p_ood = exp(α) · p_clean^γ                            (H1)
```

**γ = 1 恰好还原 H0。整篇论文归结为估计 γ 并检验 γ = 1。**

### 1.2 一行解析结果——这是论文的核心论证

考虑一组**恰好落在拟合曲线上**的策略：按定义它们的 effective robustness 全为零，
即没有任何一个比其干净成功率所预测的更鲁棒。它们的 PDR 是：

```
PDR(p_clean) = 1 − exp(α) · p_clean^(γ−1)
```

- **γ = 1** → PDR 与 p_clean 无关，是常数。PDR 是合法的鲁棒性度量。
- **γ ≠ 1** → 一组**同等鲁棒**的策略会得到**系统不同的 PDR**。
  PDR 此时排的是能力，不是鲁棒性。

所以只要测出 γ ≠ 1，PDR 的跨模型比较立刻失效，而且失效幅度可直接算出来。

### 1.3 机制：逐步复合模型给出可分离的预测

设 q 为干净条件下的单步成功概率，H 为任务的有效决策步数，单步失败独立：

```
p_clean = q^H
```

扰动使单步成功率变为 r·q（r 为单步保持率）：

```
p_ood = (r q)^H = r^H · q^H = r^H · p_clean
```

**即：最简单的复合模型恰好预测 γ = 1，且 c = r^H。**
换句话说，PDR 成立的机制条件是——**单步鲁棒性 r 与单步能力 q 无关**。这就是那个隐藏假设的物理形式。

若 r 依赖于 q（强策略每一步也更抗扰，或反之），令 ε = dlog r / dlog q，则

```
log p_ood = H log r(q) + H log q,   log p_clean = H log q
⇒ γ = dlog p_ood / dlog p_clean = 1 + ε
```

**两个可分离的预测：**

| 量 | 复合模型的预测 | 违反时意味着 |
|---|---|---|
| **γ** | = 1，且**与 H 无关** | γ ≠ 1 ⇒ 单步鲁棒性与单步能力耦合，弹性 ε = γ − 1 |
| **α_H** | = H · log r，即 **α 关于 H 过原点线性** | 非线性 ⇒ 单步失败**不独立**（存在吸收态/恢复行为），复合模型本身失效 |

> ⚠️ **修正 Stage 2 文档的一处表述。** `06_stage2_audit_result.md` 与页面里写的是
> 「log 尺度斜率应随 H 增大」。按上面的推导这是错的：**随 H 变化的是截距 α，不是斜率 γ**。
> H2 的正确表述是「α_H 关于 H 过原点线性」。两处文档已在本文件标注，引用时以本文件为准。

### 1.4 三条预注册假设

- **H1**：γ ≠ 1（LRT 在 α = 0.05 下拒绝 γ = 1）。
- **H2**：α_H 关于 H 过原点线性；偏离即为复合模型失效的证据。
- **H3**：按 PDR 排序与按曲线残差（effective robustness）排序**给出不同的模型序**。
  若两者一致 → 本工作无实践价值，**立即放弃**（这一条独立于 H1，必须显式检验）。

## 二、统计模型

两个成功率都由有限次 episode 估计，回归量本身带噪声。
**直接用观测率对观测率回归会把斜率向 0 衰减（regression attenuation），从而凭空制造出 γ < 1。**
这正是本工作要检验的效应，绝不能让方法本身产生它。

因此每个 checkpoint 的干净成功率是**潜变量** θ_i，与 (α, γ) 联合估计：

```
k_clean,i ~ Binomial(n, θ_i)
k_ood,i   ~ Binomial(n, exp(α) · θ_i^γ)
```

- θ_i 在给定 (α, γ) 时有闭式极大化解，用向量化二分求解剖掉，外层只优化 (α, γ)。
- γ = 1 的检验用似然比检验，统计量对照 χ²(1)。
- effective robustness = 观测 p_ood − 曲线预测值（概率尺度）。

实现见 `analysis/idood_model.py`：`fit()`、`lrt_proportional()`、`effective_robustness()`、`pdr()`。

**配对设计**：干净与扰动 episode 使用**同一组初始状态种子**。上述似然把两者当独立处理，
因此所有功效数字都是**保守**的，真实配对分析只会更灵敏。

## 三、实验设计

### 3.1 x 轴覆盖靠 checkpoint 扫描，不靠堆模型

要拟合一条曲线，需要干净成功率**在 x 轴上铺开**。堆不同模型既贵又引入架构混杂。

**做法：取少数几个模型，沿训练过程采样中间 checkpoint。** 每个 checkpoint 就是曲线上的一个点。
- 便宜：checkpoint 本来就会存；
- 干净：架构、数据、超参全部匹配，唯一变化的是能力水平；
- 可分离：能同时估计「模型内轨迹」与「模型间关系」，若两者不一致本身就是结果。

**硬性要求：checkpoint 必须按固定 schedule 选取（如每 N 步一存），
绝不能挑 best checkpoint。** best-of-N 选择会系统扭曲曲线右端。

### 3.2 模型池

| 模型 | 架构族 | 来源 | 4080 |
|---|---|---|---|
| OpenVLA-7B | 自回归 VLA | released + LoRA 微调 checkpoint | 4-bit ≈ 7.0 GB，推理慢，只覆盖子集 |
| SmolVLA-450M | flow-matching VLA | released + 微调 checkpoint | 可训可推 |
| Diffusion Policy | 扩散 BC | 自训（LIBERO） | 完全可控 checkpoint |
| ACT | Transformer BC | 自训（LIBERO） | 完全可控 checkpoint |

**前置检查**：checkpoint 池的干净成功率跨度必须 **≥ 30 个百分点**。
跨度不足 → 混杂本身不存在，问题不成立，按停止规则终止。

### 3.3 扰动轴与单元格

- 轴（取自 LIBERO-Plus）：相机视角、机器人初始位姿、光照、背景纹理。共 4 轴。
- 强度：每轴 3 级。
- 单元格 = (checkpoint × 轴 × 强度)。
- 每格 150 episodes（干净基线每 checkpoint 150，跨轴共用）。

### 3.4 时域分层（H2 用）

用专家演示长度作为 H 的代理，按四分位把任务分层；每层单独拟合 (α_H, γ_H)。
**H 是代理量，不是真实决策步数**——这一点必须写进论文的 limitation。

### 3.5 必须固定的混杂

- 推理超参全程固定（action horizon、去噪步数、temporal ensembling 开关）。
- 所有模型共用同一评测代码、同一成功判定、同一 max steps。
- 所有条件共用同一组初始状态种子（配对）。
- checkpoint 按固定 schedule，不做 best-of-N。

## 六、预注册停止规则

| 触发条件 | 行动 |
|---|---|
| checkpoint 池干净 SR 跨度 < 30 个百分点 | **终止**。混杂不存在 |
| Phase 1：LRT 不拒绝 γ = 1，且 γ 的 95% CI 覆盖 [0.9, 1.1] | **终止**。PDR 假设成立，核心 claim 死亡 |
| γ ≠ 1 显著，但 PDR 排序与残差排序**完全一致**（Spearman ≥ 0.95） | **终止**。数学上成立、实践上无意义（H3 失败） |
| γ 显著 ≠ 1 且改变排名，但 α_H 与 H 的关系无结构 | 继续，但机制部分砍掉，降级为纯测量学短文 |
| γ 显著 ≠ 1、改变排名、且 α_H 关于 H 线性 | **全部成立**。立刻挂 arXiv，然后按 `09_venue_timeline.md` 走 RA-L |
| 期间发现他人已发表同一实证结果 | **终止**，转 C3 |
