## 一、要检验的命题

### 1.1 现行做法与它的隐含模型

现行 VLA 鲁棒性比较有两种口径，出处均已核实：

- **(a) 直接比绝对扰动成功率**——STRONG-VLA (2604.10055)、StableVLA (2605.18287) 等。
  这等于默认各模型的干净成功率相同，是最粗的版本。
- **(b) 比相对下降率**，最常见的是 VLATest (2409.12894) 定义的
  `PDR = (p_clean − p_ood) / p_clean`。

> **引用纪律**：PDR 只能引 VLATest 与实际使用它的论文。
> **不得**引 2606.31494——其 §6.1.1 只把鲁棒性定义为蒙特卡洛经验成功率，
> 完全未涉及相对下降类指标（逐字原文见 `evidence/2606.31494_sec6.1.1.md`，
> 判定见 `12_t0_audit.md`）。

两种口径都要求知道 ID→OOD 关系才成立：(a) 要求 p_clean 相等，(b) 要求成比例。

> **措辞纪律（会影响审稿）**：不要写「PDR 的数学假设错了」。
> PDR 只是一个定义，不强制所有模型共享同一个 c。要检验的是**可比性条件**：
> *若 PDR 被用作跨模型的、独立于 nominal capability 的鲁棒性度量，
> 则其期望 retention ratio 必须近似不依赖于 clean capability。*

把 (b) 当作可跨模型比较的鲁棒性指标，要求扰动的作用是**成比例**的：

```
p_ood = c · p_clean                                   (H0)
```

嵌入幂律族：

```
p_ood = exp(α) · p_clean^γ                            (H1)
```

**γ = 1 恰好还原 H0。整篇论文归结为估计 γ 并检验 γ = 1。**

### 1.2 一行解析结果——这是论文的核心论证

考虑一组**恰好落在拟合曲线上**的策略：按定义它们的 effective robustness 全为零，
即没有任何一个比其干净成功率所预测的更鲁棒。它们的 PDR 是：

```
PDR(p_clean) = 1 − exp(α) · p_clean^(γ−1)
```

- **γ = 1** → PDR 与 p_clean 无关，是常数。PDR 是合法的鲁棒性度量。
- **γ ≠ 1** → 一组**同等鲁棒**的策略会得到**系统不同的 PDR**。
  PDR 此时排的是能力，不是鲁棒性。

所以只要测出 γ ≠ 1，PDR 的跨模型比较立刻失效，而且失效幅度可直接算出来。

### 1.3 机制：逐步复合模型给出可分离的预测

设 q 为干净条件下的单步成功概率，H 为任务的有效决策步数，单步失败独立：

```
p_clean = q^H
```

扰动使单步成功率变为 r·q（r 为单步保持率）：

```
p_ood = (r q)^H = r^H · q^H = r^H · p_clean
```

**即：最简单的复合模型恰好预测 γ = 1，且 c = r^H。**
换句话说，PDR 成立的机制条件是——**单步鲁棒性 r 与单步能力 q 无关**。这就是那个隐藏假设的物理形式。

若 r 依赖于 q（强策略每一步也更抗扰，或反之），令 ε = dlog r / dlog q，则

```
log p_ood = H log r(q) + H log q,   log p_clean = H log q
⇒ γ = dlog p_ood / dlog p_clean = 1 + ε
```

**两个可分离的预测：**

| 量 | 复合模型的预测 | 违反时意味着 |
|---|---|---|
| **γ** | = 1，且**与 H 无关** | γ ≠ 1 ⇒ 单步鲁棒性与单步能力耦合，弹性 ε = γ − 1 |
| **α_H** | = H · log r，即 **α 关于 H 过原点线性** | 非线性 ⇒ 单步失败**不独立**（存在吸收态/恢复行为），复合模型本身失效 |

> ⚠️ **修正 Stage 2 文档的一处表述。** `06_stage2_audit_result.md` 与页面里写的是
> 「log 尺度斜率应随 H 增大」。按上面的推导这是错的：**随 H 变化的是截距 α，不是斜率 γ**。
> H2 的正确表述是「α_H 关于 H 过原点线性」。两处文档已在本文件标注，引用时以本文件为准。

## 一bis、与 2602.03344 的定位（必须写进 Related Work）

**Robustness as an Emergent Property of Task Performance**（arXiv `2602.03344`，2026-02，cs.CL；
Ashury-Tahan, Gera, Bandel, Shmueli-Scheuer, Choshen）已经证明：
鲁棒性主要由 task-specific competence 驱动而非独立的模型属性，并据此建议
**减少对鲁棒性的独立测量与改进投入**。

**因此本工作不得 claim「发现能力混杂鲁棒性」。** 那已经发表了。

本工作的定位是检验其推论在**闭环序贯控制**中是否成立：

| | 2602.03344 | 本工作 |
|---|---|---|
| 任务 | 静态 NLP 推理，无时域 | 闭环操作，`p_clean = q^H` |
| 结论形式 | performance 与 robustness **相关** | ID→OOD 的**函数形式**及其可比性后果 |
| 推论 | 鲁棒性会随性能涌现，可少投入 | 若 γ≠1，该推论在机器人上不成立 |

静态任务没有逐步误差复合，这正是该推论最可能失效的地方——也是本工作唯一的立足点。

## 二、统计模型

两个成功率都由有限次 episode 估计，回归量本身带噪声。
**直接用观测率对观测率回归会把斜率向 0 衰减（regression attenuation），从而凭空制造出 γ < 1。**
这正是本工作要检验的效应，绝不能让方法本身产生它。

因此每个 checkpoint 的干净成功率是**潜变量** θ_i，与 (α, γ) 联合估计。
**结构必须是层次式的——每个 checkpoint 一条 clean 观测、多条 OOD 观测：**

```
k_clean,i   ~ Binomial(n_i,  θ_i)                       ← 每个 checkpoint 只出现一次
k_ood,i,j   ~ Binomial(n_ij, exp(α_j) · θ_i^γ_j)        ← 每个扰动条件一条
```

> ⚠️ **这是本协议最容易出错、后果最严重的一处。**
> 若把多个扰动条件拼成扁平的 `Cell` 列表送进 `lrt_proportional()`，
> 同一批 clean episodes 会被似然**重复计入 J 次**，θ_i 的不确定性被严重低估，
> **凭空制造出 γ≠1**——正是我们要检测的效应。
> **实测一类错误**（真值 γ=1.0，12 checkpoint × 3 条件 × 150 episodes，200 次重复，名义 5%）：
> **扁平池化 73.0%，层次结构 4.0%**。见 `analysis/typeI_results.txt`。
> 即：照原设计跑，有约七成概率"发现"一个并不存在的 γ≠1。
>
> **正式分析一律用 `fit_hier()` / `lrt_hier()`。**
> 扁平的 `Cell` 路径只在「单一扰动条件」时等价，保留仅为向后兼容。

**每个条件有独立的 α_j。** 相机位移与光照没有理由共用一条曲线。
`shared_gamma=False` 时还可估计每条件的 γ_j——
**耦合是否具有扰动特异性本身就是一个值得问的科学问题**，不要默认合并。

- θ_i 在给定 (α, γ) 时有闭式极大化解，用向量化二分求解剖掉，外层只优化 (α, γ)。
- γ = 1 的检验用似然比检验，统计量对照 χ²(1)。
- effective robustness = 观测 p_ood − 曲线预测值（概率尺度）。

实现见 `analysis/idood_model.py`：`fit()`、`lrt_proportional()`、`effective_robustness()`、`pdr()`。

**配对设计**：干净与扰动 episode 使用**同一组初始状态种子**。
似然把两者当独立处理，但**不得据此宣称结果一定保守**——把相关的伯努利当独立，
对差值的检验通常保守，对这里 γ 的检验则不自动成立。
因此 CI 一律用 `paired_bootstrap_gamma()` 在 **checkpoint 级**重采样得到，不靠假定。

## 三、实验设计

### 3.1 x 轴覆盖靠 checkpoint 扫描，不靠堆模型

要拟合一条曲线，需要干净成功率**在 x 轴上铺开**。堆不同模型既贵又引入架构混杂。

**做法：取少数几个模型，沿训练过程采样中间 checkpoint。** 每个 checkpoint 就是曲线上的一个点。
- 便宜：checkpoint 本来就会存；
- 干净：架构、数据、超参全部匹配，唯一变化的是能力水平；
- 可分离：能同时估计「模型内轨迹」与「模型间关系」，若两者不一致本身就是结果。

**硬性要求：checkpoint 必须按固定 schedule 选取（如每 N 步一存），
绝不能挑 best checkpoint。** best-of-N 选择会系统扭曲曲线右端。

**采样密度必须向高能力带倾斜。** 这是为了同时满足两个互相拉扯的要求：

- *功效*要求跨度宽：跨度 70 点时 γ=1.5 检出率 97.3%，30 点时只有 42.0%（§4）。
- *部署相关性*要求集中在高能力区：没人会部署 clean=20% 的 checkpoint，
  若曲率完全由垃圾 checkpoint 决定，对当前 SOTA 的比较就没有意义。

**排布方案**：低能力段（0.2–0.6）留 3–4 个锚点把跨度撑开，
其余 checkpoint 全部采在 **0.6–0.9**。这样全域拟合有功效，高能力区的 M 也够大。

**报告方式**：全域拟合作主分析；高能力区（p_clean ≥ 0.6）拟合作稳健性检查，
且**必须预先声明其功效**。高能力区不显著只能解释为功效不足，
**不得**解释为"效应在部署相关区间不存在"。

**checkpoint 扫描只能承担 discovery，不能单独支撑 generality claim。**
训练过程中变化的不只是能力，还有表征、记忆化、校准、策略平滑度。
因此必须同时报告：**模型内 checkpoint 轨迹**的斜率与**跨架构**的斜率。
两者若不一致，本身就是结果（说明发现的是训练动力学而非一般的能力律），必须如实报。

### 3.2 模型池

| 模型 | 架构族 | 来源 | 4080 |
|---|---|---|---|
| OpenVLA-7B | 自回归 VLA | released + LoRA 微调 checkpoint | 4-bit ≈ 7.0 GB，推理慢，只覆盖子集 |
| SmolVLA-450M | flow-matching VLA | released + 微调 checkpoint | 可训可推 |
| Diffusion Policy | 扩散 BC | 自训（LIBERO） | 完全可控 checkpoint |
| ACT | Transformer BC | 自训（LIBERO） | 完全可控 checkpoint |

**前置检查**：checkpoint 池的干净成功率跨度。按 §4 的功效结果：
- **≥ 60 个百分点：目标值。** γ=1.5 检出率 97%，γ=1.25 约 55%。
- **30–60 个百分点：可做但受限。** 跨度 30 点时 γ=1.5 只有 42% 检出率，
  只能检出大偏离；报告时必须声明功效限制。
- **< 30 个百分点：终止。** 混杂本身不存在，问题不成立。

拉宽跨度靠多保留早期 checkpoint，几乎零成本，**优先级高于增加 episode 数**。

### 3.3 扰动轴与单元格

- 轴（取自 LIBERO-Plus）：相机视角、机器人初始位姿、光照、背景纹理。共 4 轴。
- 强度：每轴 3 级。
- 单元格 = (checkpoint × 轴 × 强度)。
- 每格 150 episodes（干净基线每 checkpoint 150，跨轴共用）。

### 3.3bis 参考总体：曲线在哪些策略上拟合（**这条决定 H3 有没有意义**）

**不要把所有策略放进同一次拟合再看谁在曲线上方。** 一个真正鲁棒的方法会把曲线拉高，
从而抹掉自己的残差——越有效的方法越测不出来。

按 Taori 的做法分两层：

| 层 | 成员 | 作用 |
|---|---|---|
| **参考总体** | 标准训练的策略：ACT、Diffusion Policy、SmolVLA、OpenVLA 的常规 checkpoint | 拟合 `f_standard`，**只用这些点** |
| **held-out 干预** | 声称提升鲁棒性的方法：RobustVLA、STRONG-VLA、StableVLA、鲁棒训练/增广变体 | 不参与拟合，作为 held-out 打分 |

```
ER_method = p_ood(method) − f_standard(p_clean(method))
```

回答的是：**它有没有获得超出其能力提升所预期的鲁棒性？**

用 `effective_robustness_vs_reference(reference_fit, held_out_checkpoints)`。
若最终能重审 5–10 个近期 robust-VLA 方法并给出各自的 ER，
这张表就是论文最有力的结果——比提出一个新指标强得多。

### 3.4 时域分层（H2 用）

**演示长度是弱代理，不要作为唯一定义。** 录像长度同时受采样频率、专家速度、
停顿、action chunking 影响。按优先级选择 H 的操作化：

1. **benchmark 定义的子目标数**（LIBERO 任务有明确的阶段结构）——首选；
2. **固定执行接口下的 policy 调用次数**（即真实决策步数）；
3. 专家演示长度四分位——仅作为 1、2 都拿不到时的兜底，并在 limitation 中明写。

每层单独拟合 (α_H, γ_H)。**机制预测：γ 与 H 无关，α_H 关于 H 过原点线性。**

### 3.5 必须固定的混杂

- 推理超参全程固定（action horizon、去噪步数、temporal ensembling 开关）。
- 所有模型共用同一评测代码、同一成功判定、同一 max steps。
- 所有条件共用同一组初始状态种子（配对）。
- checkpoint 按固定 schedule，不做 best-of-N。

## 四、功效分析

以下**不是估计值**，是 `analysis/run_power.py` 的模拟结果（每格 150 次重复，名义水平 0.05，
α = log 0.55）。M = checkpoint 数，N = 每格 episode 数。

```
--- 干净 SR 跨度 0.20–0.90（宽，70 个百分点）---
 gamma    M  N/cell  episodes   reject   gamma_hat
  1.00   12      50      1200    5.3%   1.006 ±0.195   <- 一类错误
  1.00   12     150      3600    5.3%   1.010 ±0.110   <- 一类错误
  1.00   20     150      6000    6.7%   0.996 ±0.091   <- 一类错误
  1.25   12      50      1200   20.7%   1.253 ±0.254
  1.25   12     150      3600   55.3%   1.271 ±0.143
  1.25   20     150      6000   70.7%   1.239 ±0.096
  1.50   12      50      1200   61.3%   1.553 ±0.313
  1.50   12     150      3600   97.3%   1.515 ±0.152
  1.50   20     150      6000   98.0%   1.496 ±0.121
  2.00   12     150      3600  100.0%   2.001 ±0.192

--- 干净 SR 跨度 0.45–0.75（窄，30 个百分点）---
  1.00   12     150      3600    5.3%   1.007 ±0.254   <- 一类错误
  1.50   12     150      3600   42.0%   1.524 ±0.358
```

**三条可直接用于排期的结论：**

1. **检验是校准的。** 一类错误在所有设定下为 5.3–6.7%，估计量无偏。
   方法本身不会制造出 γ ≠ 1。

2. **每格 50 episodes 不够用。** 对中等效应（γ=1.25）只有 20.7% 的检出率，
   γ=1.5 也只有 61%。这正是 LBM 那条「50 次 rollout 置信区间 20–30 点」警告的定量版本。
   **N = 150 是下限，不是优化项。**

3. **跨度比 episode 数重要得多——这条改变设计优先级。**
   同样 3,600 个 episode、同样 12 个 checkpoint：
   干净 SR 跨度 70 点时 γ=1.5 的检出率 **97.3%**，跨度 30 点时只有 **42.0%**。
   把跨度拉宽是**零额外算力成本**的功效提升（多存几个早期 checkpoint 而已），
   而把 N 从 150 加到 300 要翻倍算力却换不到这么多。
   **优先把 checkpoint 池铺开，其次才是加 episode。**

### PDR 能力混杂的量级

对**恰好落在曲线上**（effective robustness 全为零，即同等鲁棒）的一组策略：

```
gamma=0.75   PDR 从 0.257 → 0.435   跨度 17.8 个百分点
gamma=1.00   PDR 从 0.450 → 0.450   跨度  0.0 个百分点
gamma=1.50   PDR 从 0.699 → 0.478   跨度 22.1 个百分点
gamma=2.00   PDR 从 0.835 → 0.505   跨度 33.0 个百分点
```

（干净 SR 从 0.30 到 0.90）

**只有 γ=1 时跨度为零。** γ=1.5 时，一组同等鲁棒的策略之间会出现 22 个百分点的 PDR 差异——
而文献里报告的鲁棒性改进通常只有几个百分点。**混杂量级比被声称的效应大一个数量级。**
这是论文最有力的一张图。

## 六、预注册停止规则

| 触发条件 | 行动 |
|---|---|
| checkpoint 池干净 SR 跨度 < 30 个百分点 | **终止**。混杂不存在 |

## 七bis、需要预先防守的最近邻

2606.31494 §6.1.1 末尾提到 *systematic parameter sweeps*（Chi et al. 2023）：
把扰动参数在受控范围内扫过，画性能随参数变化的曲线。审稿人很可能拿它说「已经有人做了」。

**区别必须在论文里写清楚：**

| | 参数扫描 | C1 |
|---|---|---|
| 横轴 | 扰动参数强度 | **策略的干净成功率** |
| 一条曲线 / 一个点代表 | 一个策略 | 一个策略 = 一个点 |
| 回答的问题 | 扰动多大时这个策略会崩 | **跨策略比较鲁棒性的正确方式是什么** |

两者正交，不是同一件事。
