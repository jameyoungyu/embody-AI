# Stage 1-B：Failure Mode 矿藏清单

按用户要求的 A–H 分类整理本次检索挖到的**真实失败模式**。
每条给出：现象 → 证据出处 → 是否已被解决 → 剩余空间。

标记：`[占坑]` 已有直接工作；`[部分]` 现象已知但机制/量化未做；`[空]` 本次检索未发现直接工作。

---

## A. Failure Mode（标准 benchmark 优秀，特定条件下崩溃）

| 现象 | 证据 | 状态 |
|---|---|---|
| VLA 在相机视角、机器人初始位姿轻微扰动下从 ~95% 跌到 <30% | LIBERO-Plus (2510.13626 / CVPR 2026) | `[占坑]` 现象已系统量化 |
| 物体位置位移 >0.2 单位时 OpenVLA/π0 崩溃归零，π0.5 可撑到 0.4 | LIBERO-Plus | `[部分]` 崩溃的**阈值性**（非线性）没人建模 → 见候选 C1 |
| 干净 benchmark 上 0.09B 无语言编码器的探针 ≈ SOTA | 2606.04233 | `[占坑]` |
| 生成式策略在长上下文下出现 copycat，忽略当前观测 | 2505.09561；Fighting Copycat (NeurIPS'20) | `[占坑]` |
| 3D 点云策略在真实稀疏/带噪点云上明显退化（仿真点云近乎完美） | EquiForm (2601.17486) 的动机段；DP3 相关讨论 | `[部分]` 跨模型系统量化未见 |
| 抓取检测对平面/薄物体因深度不完整而失败 | GraspNet 系工作的 failure case 讨论 | `[部分]` |
| VLM 导航的主导失败模式是目标定位而非路径塑形 | NaviTrace (2510.26909) | `[占坑]` |

## B. Hidden Assumption（论文默认成立、现实不成立）

| 隐含假设 | 现实 | 证据/状态 |
|---|---|---|
| 部署时所有训练模态都在 | 相机可能掉线、深度可能失效 | ConD (2607.20326)、2606.15514 `[占坑]` |
| 相机外参已知/固定 | 真机会漂移、会被碰 | 2510.02268、2607.05396 `[占坑]` |
| 本体感受状态是"免费的有用信息" | 它是捷径来源 | 2509.18644 `[占坑]` |
| 干净 benchmark 分数 ≈ 能力 | 存在捷径可解性 | 2606.04233 `[占坑]` |
| **鲁棒性分数可以跨模型直接比较** | **它被干净成功率强烈混杂** | **本次检索未见任何机器人论文处理 → `[空]` ← 核心空隙** |
| 仿真评测与真机的相关性（r≈0.9+）在扰动条件下依然成立 | 未经检验 | `[空]`（但需真机验证，Pilot 阶段做不了） |
| 量化只影响精度不影响行为分布 | 时序误差会累积 | DA-PTQ 提及 `[部分]` |
| 深度传感器类型一致 | 结构光/ToF/双目噪声结构完全不同 | GraspNet-1B IJRR'23 标题即"across diverse sensor qualities" `[部分]` |

## C. Dataset / Benchmark Bias

| 问题 | 证据 | 状态 |
|---|---|---|
| LIBERO 训练/测试分布差极小 → 死记硬背即可 | LIBERO-PRO (2510.03827) | `[占坑]` |
| LIBERO/CALVIN 多项诊断不合格（捷径可解、缺显著性、渐进过拟合、数据源依赖） | 2606.04233 | `[占坑]` |
| OXE 各子集质量差异巨大（分辨率、动作噪声、语言标注） | OXE 相关分析 | `[部分]` |
| 抓取 AP 指标偏向大而简单几何的物体 | Scale-balanced grasp (2212.05275) 等 | `[部分]` |
| **抓取 AP 与真实执行成功率的相关性** | 多篇提到"数据集/仿真/真机之间存在差异妨碍准确分析" | **`[空]` 未见系统量化 → 候选 C3** |

## D. Generalization Failure

| 轴 | 状态 |
|---|---|
| cross-object / cross-scene | `[占坑]`（scaling law 2410.18647 已给幂律） |
| cross-camera（视角） | `[占坑]` 2025–2026 至少 5 篇 |
| cross-sensor（深度相机类型） | `[部分]` GraspNet-1B 同时提供 RealSense/Kinect；跨相机训练/测试实验被提及但缺独立系统研究 |
| cross-embodiment | `[占坑]` GraspGen-X、AnyBody、Same Weights Different Robot (2606.03724) |
| cross-benchmark（同一模型在不同 benchmark 上排名是否一致） | `[部分]` 2606.04233 触及"data-source dependence" |
| **cross-perturbation-axis（在轴 A 上学到的鲁棒性能否迁移到轴 B）** | **`[空]` → 候选 C4**（视觉领域有先例：对抗鲁棒性不跨攻击类迁移） |

| 现象 | 状态 |

|---|---|

| **抓取检测缺同类系统 corruption 基准** | **`[空]` → 候选 C3** |

## G. Deployment Gap

| 现象 | 状态 |
|---|---|
| 推理延迟导致动作块衔接不连续 | Real-Time Chunking 等 `[占坑]` |
| 量化/蒸馏后的边缘部署 | `[占坑]` 方法侧 |
| **压缩在干净任务上无损、但在扰动条件下不成比例地退化** | `[部分]`：视觉领域有 Hooker (1911.05248) 先例；VLA 侧 DA-PTQ 提到时序漂移 → 候选 C5 |
| 同权重换机器人后的安全性 | Same Weights, Different Robot (2606.03724) `[占坑]` |

## H. Evaluation Flaw（提升到底来自哪里）

**这是本次挖掘价值最高的一类。**

| 问题 | 状态 |
|---|---|
| 干净分数的显著性 | `[占坑]` 2606.04233 |
| **鲁棒性分数的显著性 / seed 与 checkpoint 方差是否大于方法效应** | **`[空]` → 候选 C2** |
| **鲁棒性比较是否被干净成功率混杂（effective robustness）** | **`[空]` → 候选 C1（核心）** |
| 评测 episode 数量与统计功效 | 现状：多数论文 50 episodes/task、1–3 seeds、常常不报标准差 | `[部分]` |
| 推理超参（action horizon、去噪步数、temporal ensembling）作为隐藏混杂 | `[部分]` OpenVLA-OFT 等报告其重要性，但未作为"比较公平性"问题处理 |

## ⛔ 淘汰清单：这些方向现在不要做

| 方向 | 淘汰原因 |
|---|---|
| 再做一个 LIBERO 扰动变体 | 已有 Plus / PRO / X / Para 四个，边际价值趋零 |
| 给 VLA 加深度 / 加 3D / 加 flow / 加 memory / 加 CoT | 2026 年半年内 ≥10 篇同型工作，属"We add X module" |
| VLA 量化新算法 | 半年内 ≥6 篇，且工业界在推 |
| 触觉跨传感器不变表征 | ICLR'25 已定调 + 后续密集 + 我无硬件 |
| "VLA 不听语言"的新解法 | 现象与解法都已占坑 |
| 本体感受捷径 | 2509.18644 已占 |
| 相机外参/视角鲁棒性新方法 | 2025-10 起至少 5 篇 |
| 世界模型评测器 | 需大算力，且半年 ≥6 篇 |
| 人形 / 灵巧手 / 真机大规模评测 | 硬件门槛，Pilot 阶段不可行 |
| 深度补全用于抓取 | 2021 年就有专门工作，且工程上已用最近非零填充 |

## ✅ 幸存并进入 Novelty Audit 的问题

只有 5 个（详见 `03_candidates.md`）：

1. **C1** 鲁棒性比较的混杂：OOD 成功率是否只是干净成功率的函数？闭环下它的函数形式是什么？
2. **C2** 鲁棒性排名的测量可靠性：seed/checkpoint/采样噪声 vs 方法效应。
3. **C3** 抓取检测的系统 corruption 鲁棒性，以及 AP 与执行成功率在扰动下是否脱钩。
4. **C4** 鲁棒性能否跨扰动轴迁移。
5. **C5** 压缩是否用鲁棒性换干净精度。
